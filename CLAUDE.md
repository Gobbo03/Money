# Progetto: Da Niko Ortofrutta

App + sito per prenotare la spesa (consegna a domicilio o ritiro in negozio) per il negozio
"Da Niko ortofrutta". Tutti i requisiti raccolti dal titolare sono in `REQUISITI.md`:
leggilo prima di ogni modifica e aggiornalo quando il titolare dà nuove risposte.

- Lingua dell'interfaccia e dei documenti: italiano.
- `prototipo/index.html`: prototipo in un unico file (HTML/CSS/JS senza librerie), dati salvati nel
  browser con `localStorage`. Tre viste: Cliente, Negozio, Fattorino.
  Il file è scritto per essere pubblicato come pagina claude.ai, quindi non ha `<!doctype>`/`<head>`.
- Prossimo passo previsto: versione 1 con backend reale (vedi "Piano tecnico" in `REQUISITI.md`).
